# scripts – Helpers

- `prepare_librispeech.sh`, `prepare_noises.sh`, `gen_mixes.sh`: dataset utilities.
- `build_lists.sh`, `build_vbd_pairs.sh`: generate list files.
- `run_ablation_grid.sh`: quantization/pruning ablations.

### Example
```bash
bash scripts/build_lists.sh
bash scripts/gen_mixes.sh
```
